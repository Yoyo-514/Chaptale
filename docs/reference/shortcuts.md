# 快捷键

以下按 Windows 工作台和菜单中的键位整理。macOS 上请以当前应用菜单及实际行为为准，不要直接假定全部 `Ctrl` 都已映射为 `Command`。

## 文件与编辑

| 操作               | 快捷键                         |
| ------------------ | ------------------------------ |
| 保存当前文件       | `Ctrl+S`                       |
| 全部保存           | `Ctrl+Shift+S`                 |
| 关闭当前标签       | `Ctrl+W`                       |
| 撤销               | `Ctrl+Z`                       |
| 重做               | `Ctrl+Y`                       |
| 剪切 / 复制 / 粘贴 | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` |
| 全选               | `Ctrl+A`                       |
| 重命名文件树选中项 | `F2`                           |

## 搜索与视图

| 操作             | 快捷键         |
| ---------------- | -------------- |
| 当前文档查找     | `Ctrl+F`       |
| 当前文档替换     | `Ctrl+H`       |
| 打开作品全文搜索 | `Ctrl+Shift+F` |
| 放大界面         | `Ctrl++`       |
| 缩小界面         | `Ctrl+-`       |
| 重置界面缩放     | `Ctrl+0`       |
| 退出专注模式     | `Esc`          |

## 快捷键没有生效时

先检查输入焦点。编辑器、对话和设置输入框各自处理部分按键；例如 Agent 会话中的查找入口用于搜索会话内容，撤销则作用于当前可编辑区域。

如果焦点正确但仍无响应，可以从顶部菜单执行同一操作，查看菜单状态或错误提示。持续出现时，反馈应用版本、系统、焦点位置和具体按键。
