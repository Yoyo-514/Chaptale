# 术语表

界面沿用部分写作和技术术语。本页解释它们在 Chaptale 中的具体含义。

## 作品与资料

| 术语                 | 含义                                         |
| -------------------- | -------------------------------------------- |
| 作品                 | 一整个本机目录，包含正文、资料和应用记录     |
| 正文 / 章节          | 作品中正在写作的稿件文件                     |
| 资产                 | 带有结构化字段的创作资料，如角色、设定或事件 |
| 资料库               | 按类型组织和展示资产的入口                   |
| 场景卡               | 记录一场戏的目标、角色、地点和限制的资料     |
| 故事顺序             | 控制时间线排列的数字                         |
| 故事时间             | 展示给作者的时间描述，可使用自定义历法       |
| 文件头 / frontmatter | Markdown 开头两行 `---` 之间的字段           |
| 双链                 | `[[角色/林晚.md]]` 这样的作品内引用          |

## AI 协作

| 术语           | 含义                                           |
| -------------- | ---------------------------------------------- |
| Agent          | 对话及工具执行入口                             |
| 专员 / Persona | 一份具有职责、资料范围与工具配置的 AI 角色定义 |
| 技能           | 按需读取的任务说明内容                         |
| 写作参考       | 本次写作任务选定的资料集合                     |
| 冻结参考       | 保存本次输入的快照，便于之后追溯               |
| 正文基线       | 生成候选时作为比较基础的原文                   |
| 候选稿         | 尚待决定是否接受的正文修改                     |
| 差异块         | 对比视图中一组相关增删内容，也是候选接受的单位 |
| 独立审查       | 对正文或候选稿进行检查并返回结构化意见         |
| 章节结算       | 从本章整理摘要、角色状态、伏笔与事件提议       |
| 待确认提议     | 尚未接受或拒绝的资料修改                       |
| token          | 模型处理文本的计量单位；与汉字数并非一一对应   |
| 运行记录       | 某次 AI 任务的模型、来源、状态、用量和输出信息 |

## 保存与历史

| 术语       | 含义                                           |
| ---------- | ---------------------------------------------- |
| 未保存缓冲 | 当前编辑器里还没有写入磁盘的内容               |
| 外部变化   | 文件被应用之外的程序修改                       |
| 版本快照   | 特定写作操作时保留的一份文件内容               |
| 定稿       | 保存章节快照并将其标为已定稿                   |
| 云端归档   | 一份可供恢复的作品备份                         |
| 观察笔记   | 尚需结合原文核对的记录，不能直接当作已确认设定 |

不确定该用哪个功能时，先看 [AI 协作流程](/ai/workflow)或[保存、版本与备份的区别](/data/versions#save-version-backup)。
