# 常见问题

本页按问题发生的位置整理。具体错误优先看当前窗口提示，相关页面列出了进一步的操作步骤。

## 安装与作品

### 不配置模型能用吗？

能。创建作品、编辑 Markdown、搜索、资料管理和查看已有版本都可以使用。对话、候选稿、独立审查与章节结算才需要可用模型。

### 找不到作品保存的位置

打开「设置 → 作品」查看当前路径。没有打开作品时，可从「文件 → 打开最近作品…」选择。迁移目录时应保留完整作品，而不只复制正文。

### 可以导入 Word 或 PDF 吗？

本手册的已有稿件流程使用 Markdown 文件，不包含 Word 或 PDF 转换。先用其他工具转为 Markdown，检查段落与标题，再放进作品目录。见[管理作品](/guide/workspace)。

### 会自动更新应用吗？

当前没有应用内自动更新。新版本和安装包以 [GitHub Releases](https://github.com/Yoyo-514/Chaptale/releases) 为准。

## 编辑与资料

### 保存成功后，为什么没有新版本快照？

保存更新磁盘文件。版本快照只在接受候选、结算、定稿、回滚等特定操作节点产生。普通编辑可以用撤销重做，长期保留稿件应配置[备份](/data/backup)。

### 搜索结果能打开文件，却不能定位

搜索之后文件已经变化，或存在未保存内容。先保存、处理外部变化，再重新搜索。见[搜索与定位](/guide/search)。

### 角色或事件文件存在，为什么视图中看不到？

检查类型字段、筛选条件、归档状态和资料库诊断。时间线使用故事事件资产，关系图使用角色及其关系字段；正文提到某个角色或事件不会自动生成结构化资料。见[资料库](/guide/library)。

### 故事时间写了日期，排序还是不对

时间线按数字“故事顺序”排序，“故事时间”仅作为文字显示。填写顺序后再核对；允许用中间值插入事件。见[故事时间线](/guide/timeline)。

## AI 配置与写作

### 有模型，但任务提示“没有可用模型”

检查供应商是否已保存、模型 ID 与凭据是否有效，以及本次任务或专员是否选择了不可用模型。默认模型与任务选择可能不同。见[配置模型](/ai/models)。

### Agent 显示“离线”，为什么仍然联网？

该开关关闭联网搜索。模型仍使用配置的服务地址，网页抓取和缓存读取也有独立行为。详见[文件、权限与隐私](/data/security)。

### 候选稿为什么不能接受？

若显示「正文已变化」，说明生成时的正文基线已过期，需要基于当前正文重新生成。若文件尚未保存或有冲突，先处理文件状态。见[候选稿](/ai/candidates)。

### “接受选区”会只改选中的字吗？

它接受与选区相交的完整差异块。提交前核对块范围；需要更细的调整时，可以手动修改或缩小生成范围。

### 审查标记“已处理”后，正文为什么没变？

这个操作只更新问题状态。需要自行修改正文，或用「提出修订」生成候选并接受。见[独立审查](/ai/reviews)。

### 结算提议处理完了，为什么还没完成？

所有提议都接受或拒绝后，还需要点击「完成结算」。若正文在途中变化，应重新结算。见[章节结算](/ai/settlement)。

## 备份与恢复

### 保存到本机就等于备份到云端了吗？

不等于。Chaptale 云端归档需要登录、绑定位置并执行备份；OneDrive 本机目录的上传由官方客户端负责。分别检查归档列表或客户端状态。

### 云端账户为什么显示“未配置”？

当前构建没有启用该云服务所需配置，不能只靠输入个人账号解决。可以先复制完整作品目录留存副本。

### 恢复时为什么只能选“新增”？

归档无法证明属于当前作品，例如缺少作品身份信息或身份不匹配。恢复到新目录后核对内容，避免覆盖另一部作品。

### 换设备后，画布位置或模型配置没跟过来

作品文件、画布布局与模型配置存放范围不同。关系内容在作品资料中，画布排布保存在本机；模型和账户也需要在新设备检查。见[数据位置说明](/data/security)。

## 提交故障信息

向 [Issues](https://github.com/Yoyo-514/Chaptale/issues) 提供：

1. Chaptale 版本、操作系统与处理器架构。
2. 从哪个入口开始，依次执行了哪些步骤。
3. 预期结果、实际结果及完整错误文字。
4. 可以公开的截图或脱敏运行 ID。

配置路径从「帮助 → 配置与诊断」查看。不要公开 API Key、包含凭据的配置文件或未脱敏的作品原文。
