# 设置速查

从活动栏左下角打开「设置」。设置窗口可以移动和调整大小；各页保存方式以页面按钮和状态提示为准。

## 设置目录

| 分类       | 主要用途                                         | 详细说明                     |
| ---------- | ------------------------------------------------ | ---------------------------- |
| 专员与内容 | 管理专员、技能、模板，导入导出与归档             | [内容管理](/ai/content)      |
| 作品       | 查看作品与会话路径，打开或关闭作品，显示内部文件 | [管理作品](/guide/workspace) |
| 模型       | 管理供应商、凭据、模型列表与默认模型             | [配置模型](/ai/models)       |
| Prompt     | 编辑基础与追加提示词                             | 本页下方                     |
| 联网       | 搜索服务、密钥及网页抓取限制                     | 本页下方                     |
| 权限       | 查看并撤销作品级和全局持久规则                   | [权限与隐私](/data/security) |
| 云端备份   | 账户登录、目录绑定、备份与恢复                   | [备份与恢复](/data/backup)   |
| 配置文件   | 显示设置文件路径并打开配置目录                   | 本页下方                     |

## Prompt 自定义

| 字段                 | 保存到             | 作用                           |
| -------------------- | ------------------ | ------------------------------ |
| System Prompt        | `SYSTEM.md`        | 完整基础提示词，不能为空       |
| Append System Prompt | `APPEND_SYSTEM.md` | 可选追加内容，放在基础提示词后 |

编辑后点击「保存 Prompt 设置」，从下一次请求开始生效。

「恢复默认 System Prompt」只改变当前草稿，仍需保存；「放弃修改」则丢弃尚未保存的编辑。提示词会发送给模型服务，不能用来保管密钥。

## 联网与内容提取

### 搜索服务

| 服务         | 是否需要 API Key |
| ------------ | ---------------- |
| DuckDuckGo   | 不需要           |
| Brave Search | 需要             |
| Tavily       | 需要             |
| Exa          | 需要             |

选择服务后填写对应凭据并保存。模型服务的 API Key 与搜索服务的 Key 分开配置，不能相互替代。

关闭「启用联网搜索」只影响搜索工具。网页抓取与缓存检索不受该开关影响，模型请求也照常发送。

### 抓取高级选项

| 选项          | 用途                                               |
| ------------- | -------------------------------------------------- |
| 抓取超时      | 限制单次网页抓取等待时间                           |
| 正文大小上限  | 限制读取的内容大小                                 |
| SSRF 放行网段 | 为确有需要的内网地址设置允许范围；留空阻止内网地址 |

只有明确知道目标与网络范围时再调整内网放行规则。普通公网查资料通常无需更改这一项。

## 配置文件与诊断

「设置 → 配置文件」提供本机文件实际路径与打开目录入口。「帮助 → 配置与诊断」也可到达相关设置。

模型无法连接时先查[模型配置](/ai/models#connection-problems)；文件状态异常时查看[编辑器冲突处理](/guide/editor#external-conflicts)；AI 任务细节可查[运行记录](/ai/history)。

## 不在设置窗口中的选项

| 选项                           | 入口             |
| ------------------------------ | ---------------- |
| 主题、缩放、面板显隐、专注模式 | 顶部「视图」菜单 |
| 保存、全部保存、自动保存       | 顶部「文件」菜单 |
| 定稿和文档版本                 | 顶部「写作」菜单 |
