# 独立审查

独立审查检查已保存正文或候选稿，返回带原文位置、理由和修改建议的问题。它可以在没有生成候选稿的情况下单独使用。

## 选择检查方向

| 方向 | 适合检查 |
| --- | --- |
| 连贯性 | 情节前后、信息和设定之间是否矛盾 |
| 角色 | 行为与动机是否符合人物资料 |
| 文风 | 表达、节奏和风格问题 |
| 自定义审查专员 | 你在「专员与内容」中配置的检查要求 |

模型给出的严重度和判断仍需结合原文核对。没有发现问题，也不等于稿件经过了完整事实验证。

## 启动一次审查

1. 保存当前正文；如果审查候选，打开候选并点击「审查候选稿」。
2. 从「审查」菜单或右侧面板进入启动窗口。
3. 核对目标是已保存正文还是候选稿。
4. 勾选需要的审查专员，确认模型和参考快照。
5. 点击「启动审查」。

可以只运行一个方向，也可以运行已启用的多个专员。列表为空时，到「设置 → 专员与内容」启用审查专员。

## 阅读与处理问题

结果按严重度、类型和处理状态筛选。每项会列出原文引用、原因和建议。

| 操作 | 用途 |
| --- | --- |
| 定位 / 点击原文引用 | 跳到被检查的内容 |
| 已处理 | 标记这条意见已经处理 |
| 忽略 | 保留记录，但不采用这条意见 |
| 提出修订 | 根据选中问题准备修订候选 |

**标记“已处理”不会替你修改正文。** 可以自行修稿，也可以选择「提出修订」，检查改动范围和模型后生成候选，再按[候选流程](/ai/candidates)接受修改。

审查中心用于集中回看问题，右侧面板用于查看某次审查的细节。

## 正文变化后如何处理

问题定位依赖审查时的原文。正文被修改后，某些问题会显示「原文已变化」，失去可靠定位。

此时先查看当前正文，不要按旧意见直接套用修改。大量未处理问题已经失去定位时，应用会建议重新审查。

参考资料变化也会使旧快照过期。通常使用最新参考重新运行；只有明确需要复查旧输入时，才选择允许旧快照。

## 调整审查偏好

连续忽略同类问题后，界面可能提示「调整检查」。打开后可以编辑偏好内容，确认后用于后续检查；这类偏好会**跨作品生效**。

不希望改变检查规则时，可以不接受该建议或选择「不再提示」。忽略一条具体意见和确认长期偏好是两件不同的操作。
