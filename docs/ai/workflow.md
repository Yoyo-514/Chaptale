# AI 协作流程

Chaptale 提供对话、候选稿、独立审查和章节结算。可以只用 AI 讨论一个想法，也可以让它参与章节修订；写作不要求完成一套固定流程。

使用这些功能前，需要打开作品并[配置可用模型](/ai/models)。

## 选择合适的入口

| 你想做什么                   | 使用什么                                              | 得到什么                       |
| ---------------------------- | ----------------------------------------------------- | ------------------------------ |
| 讨论情节、查阅资料、整理思路 | [Agent 对话](/ai/chat)                                | 对话回复及相应工具结果         |
| 续写一段或修改正文           | [写作参考](/ai/references) + [候选稿](/ai/candidates) | 可比较、可部分接受的修改       |
| 检查连贯性、角色行为或文风   | [独立审查](/ai/reviews)                               | 带理由、建议和原文位置的问题   |
| 整理写完一章后的资料变化     | [章节结算](/ai/settlement)                            | 摘要、角色状态、伏笔及事件提议 |
| 核对某次生成用了什么         | [运行记录](/ai/history)                               | 模型、来源、用量和留档输出     |

## 示例：改好一段人物对话

### 1. 保存正文，说明写作目标

打开要修改的章节，选中目标段落并保存。在「参考」里写下具体目标，例如：

> 保留双方交换信件的结果，缩短解释背景的台词。林晚只试探，不直接质问；顾沉不能承认自己读过信。

### 2. 检查本次参考

加入两个人物的资料和有关信件的设定。展开原文检查内容，删除不相关的来源。参考较长时，使用要点模式或调整预算。

### 3. 生成并比较候选稿

点击「生成候选稿」，确认目标章节、写入范围与模型。候选生成后，查看正文基线与候选稿的差异，接受需要的块。

### 4. 按需要运行审查

若担心台词偏离人物设定，可单独运行角色审查。认同某条意见时自行修改，或通过「提出修订」生成另一份候选。

### 5. 完成本章后整理事实

章节写完并保存后，运行结算。检查新摘要、人物状态和事件是否有原文依据，再处理提议。中途的一次小修改不必立即结算整章。

## 哪些操作会改文件

| 操作                         | 写入行为                                           |
| ---------------------------- | -------------------------------------------------- |
| 生成候选稿                   | 保存候选记录，尚不替换正文                         |
| 接受候选差异                 | 把选定差异写入目标正文                             |
| 运行审查                     | 生成意见；提出修订会生成候选                       |
| 接受结算提议                 | 写入提议对应的摘要或资料文件                       |
| 勾选“本次自动接受摘要”后结算 | 本次生成的摘要可自动接受                           |
| Agent 调用文件工具           | 依照工具权限与已有授权执行，可能直接创建或编辑文件 |

::: info 对话与候选的区别
“候选生成不会改正文”只描述候选流程。Agent 对话中的文件工具有自己的授权机制；已保存的允许规则可能使后续操作无需再次询问。详见[权限与隐私](/data/security)。
:::

## 遇到结果不合适时

候选不合适可以放弃，审查意见可以忽略，结算提议可以拒绝。先检查目标、来源和修改范围，再决定是否换模型重试；重复发送同一请求未必能解决参考遗漏。

正文或资料已经变化时，旧候选与旧提议可能失效。应基于最新内容重新生成，避免将旧结果覆盖回新稿。
