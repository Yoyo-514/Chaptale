# Agent 对话

Agent 用于讨论情节、查阅作品资料和执行工具任务。需要打开作品，并在[模型设置](/ai/models)中配置可用模型。

## 开始一段对话

1. 在右侧辅助栏选择「Agent」。
2. 检查当前专员，输入具体问题。
3. 需要资料时，用「添加文件」选择本轮上下文，也可将文件拖入输入区。
4. 核对附件和联网开关后发送。

例如：

> 参考这两份人物资料，列出他们在码头见面时各自想隐瞒的事。先讨论动机，不修改文件。

指定期望结果和是否需要改文件，有助于减少不必要的工具操作。

## 会话与专员

「Agent → 新建会话」开始新的讨论。通过历史视图可以回看已有会话；记录按作品保存。

专员决定本次对话的职责、可用工具和资料范围。已有消息时切换专员，界面会要求确认。需要长期使用某种写作方式，可以在[专员与内容](/ai/content)中创建专员。

一个会话积累了很多互不相关的讨论后，可以新建会话并重新提供必要资料。界面出现上下文压缩建议时，可以选择「压缩后继续」；压缩会整理较早的内容，重要约束仍建议明确保存在作品资料中。

## 给本轮对话提供材料

输入区附件属于本轮上下文。发送前检查文件列表，移除无关或不应发给模型的文件。

它与右侧「参考」面板分别服务于两种任务：

| 入口 | 使用场景 |
| --- | --- |
| 对话输入区的「添加文件」 | 对这次提问附上材料 |
| 「参考」面板 | 为候选、审查等写作任务核对来源、控制预算并保存快照 |

## 联网与工具授权

输入区可切换联网搜索，搜索服务在「设置 → 联网」配置。“离线”表示关闭联网搜索，模型请求仍会发往你配置的服务；网页抓取与缓存读取也有独立行为。

专员可以使用其配置允许的工具。需要授权时，先读目标路径和请求内容，再决定是否允许。已有持久授权的操作可能不再逐次询问；撤销规则见[文件、权限与隐私](/data/security)。

## 重试、分支与停止

- 用户消息的「编辑并重试」可修改问题后再次发送。
- 回复的「重新生成」可重新尝试同一轮。
- 出现多个分支时，通过消息旁的分支导航切换。
- 运行中可以停止当前任务，之后检查已经完成的回复和工具结果。

停止生成不会自动撤销此前已完成的文件写入。需要按差异逐块决定正文修改时，使用[候选稿](/ai/candidates)更合适。

## 查找历史内容

会话内可使用搜索入口定位文字；需要找跨文档的内容，则使用[作品搜索](/guide/search)。想核对某次 AI 任务的模型、用量和留档输出，打开[运行记录](/ai/history)。
