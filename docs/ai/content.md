# 专员、技能与模板

在「设置 → 专员与内容」管理可复用的创作配置。它们以内容定义的形式存在，编辑前可以检查具体文字和字段。

## 三类内容的分工

| 类型 | 决定什么                                      | 例子                   |
| ---- | --------------------------------------------- | ---------------------- |
| 专员 | AI 的职责、资料范围、工具、模型偏好与绑定技能 | 人物动机讨论、独立审查 |
| 技能 | 专员按需读取的任务说明                        | 某种题材的检查方法     |
| 模板 | 新建资料的字段和正文结构                      | 角色卡、场景卡、事件   |

当前扩展范围是这些内容定义，不包含任意代码插件、MCP 服务接入或插件市场。

## 选择生效范围

| 来源     | 使用范围           | 编辑方式               |
| -------- | ------------------ | ---------------------- |
| 内置     | 随应用提供         | 只读，可查看           |
| 所有作品 | 本机多个作品共用   | 可创建和管理自定义内容 |
| 当前作品 | 只对打开的作品使用 | 适合本作设定和专用模板 |

列表同时显示停用、归档或已覆盖等状态。遇到“内容存在却没生效”时，先检查来源和状态，不要只看名称。

## 创建一个专员

1. 打开「专员」标签，点击「新建专员」。
2. 选择范围，填写标识、名称与职责说明。
3. 决定用于「对话与构思」还是「独立审查」。
4. 配置模型偏好、可读资料、工具和绑定技能。
5. 保存并检查启用状态，再回到对应入口使用。

对话专员可以配置观察保存和事实变更提议；独立审查专员的工具与输出有相应限制。应按实际任务配置所需能力。

专员的工具配置与工具调用授权共同影响执行行为，持久权限规则见[权限与隐私](/data/security)。

## 导入与导出

**导出**：勾选需要分享的条目，点击「导出所选」，生成版本化 JSON 内容包。

**导入**：点击「导入」，先预览，再选择需要的条目和导入范围。检查重名、覆盖及引用诊断后再保存。

导入的专员默认停用，并移除本机模型与权限配置。导入完成后需要重新核对能力和模型，确认后启用。分享前也应检查文字中是否夹带个人信息或作品内容。

## 归档、恢复与永久删除

归档用于暂时停用自定义内容，可以切到「已归档」列表恢复。永久删除需要确认，不进入系统回收站。

删除前检查其他专员或模板是否引用它；失效引用会保留在界面中供修复。内置项不能按自定义项的方式修改或删除。

创建资产所用模板的日常操作，见[模板与场景卡](/guide/templates)。
