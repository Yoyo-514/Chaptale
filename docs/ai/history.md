# 记忆与运行记录

“记忆”保存作品中可阅读的笔记与摘要；“运行记录”保存 AI 任务的信息。两者分别回答“留下了什么资料”和“这次任务如何完成”。

## 查看作品记忆

点击左侧活动栏的「记忆」，可按关键词筛选以下内容：

| 分组           | 内容                         |
| -------------- | ---------------------------- |
| 待确认提议     | 尚未接受或拒绝的资料变更     |
| 观察笔记       | Agent 或写作过程中留下的观察 |
| 章节与近况摘要 | 对已发生内容的概括           |

点击笔记或摘要可打开源文件。它们保存在作品目录中，能够查看和修改；“观察”并不自动等于已确认设定。

打开待确认提议后，比较当前资产与提议内容，再接受或拒绝。存在文件冲突时先处理冲突。

## 查看一次 AI 运行

打开右侧「运行」，或选择「Agent → 查看运行记录」。可以按任务、文件、运行 ID 搜索，也可按角色与成功、失败、取消、超时等状态筛选。

选择一条记录，重点核对：

- **任务与目标**：处理了哪个文件，属于哪次候选、审查或结算。
- **模型**：实际使用的供应商与模型。
- **用量**：输入和输出 token，以及服务返回的其他用量信息。
- **来源与输出**：使用的参考、关联记录和留档内容。

列表存在更早记录时，点击「加载更早记录」。

## 追查一处正文修改

1. 从[文档版本](/data/versions)比较修改前后的内容。
2. 如果变化来自候选，打开对应候选查看目标和接受情况。
3. 从候选或审查详情点击「查看运行」。
4. 对照参考来源、模型及留档输出，判断问题来自输入、生成还是后续处理。

文档快照、运行记录和记忆无法相互替代：快照保存文件版本，运行记录描述任务，记忆是之后可能继续使用的资料。

## 记录不完整时

旧记录可能缺少输出指纹或完整输出，界面会提示。读取失败时先看诊断，不要把空白直接理解为模型没有返回内容。

服务未提供的用量不应当作零消耗；估算 token 也不是账单。提交故障信息时，优先提供运行 ID 与脱敏错误，不要直接公开留档中的私人正文。
