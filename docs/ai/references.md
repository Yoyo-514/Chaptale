# 组装写作参考

写作参考决定一次生成会带上哪些作品资料。生成前看一遍来源，通常比让模型反复重写更有用。

**入口：右侧「参考」，或「写作 → 组装写作参考」。**

## 确定写作目标

可以选择已有[场景卡](/guide/templates)，也可以保留「临时写作目标」，直接说明这一段要发生什么、写到哪里以及限制条件。

例如：

> 写林晚第一次进入灯塔的场景，以她发现门后有人收拾过为结尾。保留她对顾沉的戒心，不解释旧案真相。

选择场景卡后，检查目标章节和自动带入的资料；卡片引用失效时，面板会列出未采用来源。

## 添加和检查来源

有两种常用入口：

- 在目录树或资产右键菜单中选择「加入写作参考」。
- 在参考面板的「未采用建议」中筛选资料，点击加入。

来源分成「已固定」和「自动选择」。每条来源可以查看文件、字数、更新时间及选择原因，也可展开「原文」。

| 操作       | 用途                                     |
| ---------- | ---------------------------------------- |
| 固定参考   | 将重要资料放入固定来源组                 |
| 取消固定   | 调整该来源的固定状态                     |
| 要点模式   | 使用较精简的资料内容；切换后检查实际参考 |
| 移除参考   | 本次不使用这份资料                       |
| 恢复已移除 | 将此前排除的来源重新纳入考虑             |
| 重组参考   | 重新读取并组装当前来源                   |

## 控制参考大小

面板显示字数、估算 token 数和参考字数预算。超出预算时，最大来源会被标出，便于定位最占空间的文件。

优先移除无关资料，再考虑将长资料切为要点模式。参考预算只约束这部分资料；完整请求还包含系统提示、目标正文等内容，估算 token 也不等于服务返回的实际用量。

## 冻结参考

点击「冻结参考」后，会保存一份本次输入的快照。之后查看候选或运行记录，可以追溯当时使用的来源。

生成候选前也会冻结当前参考，因此不必为每次操作重复手动点击。

::: info “来源已更新”意味着什么
原资料在快照之后发生了变化。旧快照仍表示当时的输入，但不再代表最新设定。一般应重组并生成新快照；任务确认窗口允许明确选择使用旧快照。
:::

## 来源无法读取时

面板会显示错误及无法采用的文件。先检查文件是否被移动、删除或出现格式问题；不再需要的来源可以从列表移除。

参考准备好后，保存目标章节，再[生成候选稿](/ai/candidates)。
