# 生成与处理候选稿

候选稿保存一次 AI 提出的正文修改。生成后可以与原文比较，按差异块接受，也可以全部放弃。

## 生成前的准备

- 打开并保存目标 Markdown 正文。
- 处理未保存修改或外部文件冲突。
- 在[参考面板](/ai/references)填写写作目标并检查来源。
- 确认有可用模型。

如果从场景卡进入，需要关联有效章节；应用会转到目标章节准备生成。

## 选择写入范围

点击「生成候选稿」，在「创建候选稿」窗口检查章节、目标、参考快照和模型。

| 范围 | 效果 |
| --- | --- |
| 替换正文 | 为正文部分生成替换内容 |
| 追加到正文末尾 | 在现有正文之后续写 |
| 在光标处插入 | 将新增内容放到光标位置 |
| 替换选区 | 修改当前选中的正文范围 |

光标和选区选项取决于编辑器当前选择，且需要处于正文部分。**没有正文选区时，默认范围可能是“替换正文”**；续写之前应主动改成「追加到正文末尾」。

点击「创建候选」后开始生成，可以在候选面板取消。此时原正文尚未被候选替换。

## 比较与接受

生成完成后打开「候选差异」，左侧为正文基线，右侧为候选稿。

| 操作 | 会接受什么 |
| --- | --- |
| 接受当前块 | 下拉框当前选中的差异块 |
| 接受选区 | 与差异视图选区相交的完整差异块 |
| 全部接受 | 所有剩余差异；还需确认文件及增删字符数 |
| 放弃候选 | 停止处理这份候选，保留已经接受的正文变化 |

::: warning 选区以差异块为单位
「接受选区」并不保证只替换鼠标选中的几个字。提交前核对相交的差异块；若要更小的修改，可以手动编辑正文或重新生成较小范围的候选。
:::

部分接受后，可继续检查剩余差异。不确定候选是否符合设定时，先点击「审查候选稿」再决定。

## 状态与下一步

| 状态 | 含义与处理 |
| --- | --- |
| 准备中 / 生成中 | 等待完成，或取消任务 |
| 待处理 | 可以比较并接受差异 |
| 部分接受 | 已写入部分修改，仍有剩余差异 |
| 已接受 | 这份候选的修改已处理完成 |
| 正文已变化 | 生成时的基线已过期，不能直接接受 |
| 失败 / 已取消 | 检查错误，可基于当前正文重新生成 |
| 已放弃 | 不再处理这份候选 |

出现「正文已变化」时，使用「基于当前正文重新生成」。不要为接受旧候选而撤销自己已经写好的新内容。

## 回看与追溯

「查看运行」可打开本次任务的模型、用量与输出记录。接受候选相关的快照可从[文档版本](/data/versions)查看。

放弃候选不会撤销已经接受的块；需要退回旧稿时，应比较版本后再回滚。
