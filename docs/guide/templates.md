# 模板与场景卡

模板用于创建带有固定字段和正文结构的文件。场景卡则记录一段场景要写什么、涉及谁，以及不能提前揭露哪些信息。

## 从模板新建

1. 在作品侧栏、资料库或「文件」菜单中选择「从模板新建」。
2. 选择模板并填写表单。
3. 检查保存目录和文件名。
4. 点击「创建文件」，继续补充正文。

模板中的必填项需要填写。出现模板诊断时，先按提示修复模板或切换到可用模板。

| 模板类别 | 内置内容 |
| --- | --- |
| 正文与提纲 | 章节、粗纲、细纲 |
| 人物 | 主要角色、次要角色 |
| 设定 | 世界观、地点、势力、物品、能力体系 |
| 情节安排 | 伏笔、场景卡、故事事件 |

新建后的文件独立保存。后续修改模板不会替你批量改写已经创建的稿件。

## 用场景卡准备一场戏

选择「文件 → 新建场景卡…」，或在模板列表中选择场景卡。

| 字段 | 需要记录什么 |
| --- | --- |
| 所属章节 | 这场戏准备写入哪一章 |
| 出场角色、地点 | 需要参考的人物和场景 |
| 相关伏笔 | 本场会推进或涉及的伏笔 |
| 场景目标 | 这段内容结束时，情节应发生什么变化 |
| 禁忌 | 不能发生、不能揭露或需要避免的内容 |
| 情绪基调 | 例如紧张、克制、轻松 |
| 目标字数 | 本场的长度参考 |
| 已结算 | 是否已经完成相应结算 |

例如，一场“码头交换信件”的目标可以写成：

> 林晚拿到信，但没有发现信封被换过。顾沉用一句话试探她是否认得封蜡。结尾让守夜人的脚步声打断谈话。

禁忌另填“不要揭露寄信人的身份”。目标与限制分开填写，后续核对参考时更容易发现遗漏。

## 把场景卡用于 AI 写作

1. 打开右侧「参考」。
2. 在「场景」中选中这张卡。
3. 核对带入的写作目标和自动选择的来源。
4. 补充或移除参考，再[生成候选稿](/ai/candidates)。

如果从场景卡直接生成候选，卡片需要关联有效章节；没有关联时，应先选定目标正文。目标字数是给模型的参考，不保证输出恰好达到该数字。

## 自定义模板

到「设置 → 专员与内容」管理模板。内置模板只读，自定义模板可用于所有作品或仅当前作品，也能导入导出。

模板属于内容扩展，具体管理方式见[专员、技能与模板](/ai/content)。
