# 认识工作台

Chaptale 围绕当前打开的作品组织界面。写正文、查资料、与 AI 对话时，可以保留同一部作品的上下文。

![工作台：左侧作品目录、中央章节、右侧 Agent](/screenshots/workbench.png)

## 界面区域

| 区域         | 包含什么                                  | 常见用途                               |
| ------------ | ----------------------------------------- | -------------------------------------- |
| 顶部菜单     | 文件、编辑、视图、写作、Agent、审查、帮助 | 保存、创建章节、启动写作任务、调整视图 |
| 左侧活动栏   | 作品、搜索、资料库、审查中心、记忆        | 选择当前需要的侧栏                     |
| 左侧作品侧栏 | 文件树或所选功能的列表                    | 找章节、筛选资料、查看问题             |
| 中央工作区   | 文档标签、资料库、时间线、角色关系        | 编辑与查看作品内容                     |
| 右侧辅助栏   | Agent、参考、候选、审查、结算、资产、运行 | 与 AI 协作，查看当前任务详情           |
| 底部状态栏   | 当前编辑状态等信息                        | 核对文件和编辑状态                     |

在文件树中单击文件，会在中央打开标签。切到时间线或角色关系后，可以通过工作标签返回正文。

## 按任务找入口

| 想做什么                 | 从哪里进入                            |
| ------------------------ | ------------------------------------- |
| 新建或打开作品           | 「文件」菜单                          |
| 创建章节或场景卡         | 「文件 → 新建章节… / 新建场景卡…」    |
| 找整部作品里的文字       | 左侧「搜索」，或 `Ctrl+Shift+F`       |
| 查看角色、伏笔和设定     | 左侧「资料库」                        |
| 让 AI 写一段候选稿       | 「写作 → 组装写作参考」，再生成候选   |
| 检查连贯性、角色或文风   | 「审查」菜单                          |
| 查看章节旧版本           | 「写作 → 查看文档版本」               |
| 查模型配置及本机文件位置 | 左下角「设置」；「帮助 → 配置与诊断」 |

## 调整阅读和写作空间

「视图」菜单可以切换侧栏、辅助栏和状态栏，也能进入专注模式。专注模式适合只看正文，按 `Esc` 退出。

界面提供浅色、暖色和深色主题。文字或控件偏小时，可以通过「视图」缩放，或使用 `Ctrl++`、`Ctrl+-`、`Ctrl+0`。

窗口较窄时，工作台会调整区域呈现方式。如果暂时看不到某个面板，先检查活动栏和「视图」菜单。

## AI 面板之间的关系

右侧各面板有独立用途，并不要求每次写作都从头走一遍：

- **Agent**：讨论想法、询问资料、执行经授权的工具任务。
- **参考 / 候选**：明确本次输入，生成并比较正文修改。
- **审查 / 结算**：检查稿件，整理本章带来的资料变化。
- **运行**：核对某次 AI 任务的模型、用量和输出记录。

第一次使用时，建议按 [AI 协作流程](/ai/workflow)中的示例完成一次小范围修改。
