# 创建和管理作品

一部作品对应一个本机目录。正文、设定、角色文件和应用记录都围绕这个目录保存；作品名称与目录名可以不同。

## 新建作品

选择「文件 → 新建作品…」，填写以下内容：

| 选项 | 用途 |
| --- | --- |
| 作品名称 | 应用中显示的作品名 |
| 作品类型 | 小说或剧本 |
| 目录名、存放位置 | 决定作品实际保存的文件夹 |
| 资料库目录 | 正文和设定始终创建；大纲、角色、伏笔、草稿、灵感、模板可按需选择 |
| 创建第一章 | 创建并打开初始章节，方便立即写作 |
| 创作守则 | 记录叙述方式、风格要求或创作约束，保存为设定文件 |

点击「创建并打开」后，应用进入新作品。目录大致如下，具体子目录取决于创建时的选择：

```text
雾港来信/
├─ chaptale.json
├─ 正文/
│  └─ 0001-第一章.md
├─ 设定/
│  └─ 创作守则.md
├─ 角色/
└─ .chaptale/
```

`chaptale.json` 记录作品信息；`.chaptale/` 用于应用记录，随使用逐步产生。日常写作无需手动编辑内部文件。

如果创建失败并提示保留了部分文件，先检查提示中的路径。不要直接把这个目录当成空目录重复创建。

## 打开、切换和关闭作品

- **打开**：「文件 → 打开作品…」，选择作品根目录。
- **最近使用**：「文件 → 打开最近作品…」。
- **关闭**：使用「文件」菜单或「设置 → 作品」中的关闭入口。
- **查看位置**：「设置 → 作品」会显示当前作品和会话目录。

切换或关闭时，先处理应用列出的未保存文档。会话与作品关联，打开另一部作品后，不会继续显示上一部作品的同一段会话。

## 整理文件

作品侧栏顶部可以新建文件、新建文件夹或从模板新建。选中文件或目录后，右键菜单提供相应操作：

| 操作 | 适用情况 |
| --- | --- |
| 重命名 | 调整章节或资料文件名；也可按 `F2` |
| 移动 | 将文件或目录放到合适的位置 |
| 复制文件 | 从现有稿件建立另一份文件 |
| 复制相对 / 绝对路径 | 引用作品内资料，或在系统工具中定位 |
| 加入写作参考 | 将文件带入本次 AI 写作的参考列表 |

重命名或移动涉及引用的文件后，应检查场景卡和资料中的关联是否仍然有效。不要把文件路径变化当作所有引用都已自动修复。

## 使用已有稿件

已有 Markdown 文件可复制到作品的正文目录，再从文件树打开。普通文本可以先整理为 Markdown；直接复制文件不会为它补齐角色、事件等资产字段。

如果希望稿件或资料进入结构化视图，使用[模板](/guide/templates)建立文件，或检查对应的文件头字段。资料库的识别规则见[资料库与资产](/guide/library)。

## 迁移到其他位置或设备

1. 保存全部文档，停止仍在运行的写作任务并关闭作品。
2. 复制完整作品目录，包括 `chaptale.json` 与隐藏的 `.chaptale/`。
3. 在新位置使用「打开作品」进入，检查正文和资料是否齐全。
4. 在新设备上检查模型配置与云端账户；这些本机设置不会随正文文件自动配置好。

迁移后先验证副本再处理原目录。需要通过云端传递完整归档时，见[备份与恢复](/data/backup)。
