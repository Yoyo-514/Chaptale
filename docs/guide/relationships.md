# 角色关系

角色关系画布显示作品中的人物及其关系。适合检查师徒、亲属、同盟等联系，也可以直接建立或修改关系。

从「资料库」打开「角色关系」。

![角色关系画布：林晚、顾沉与一条有方向的关系](/screenshots/relationships.png)

## 建立一条关系

先确保两个人物都有角色资产；没有时，可以从角色模板新建。

1. 点击「新建关系」，或在角色的右键菜单中选择「新建角色关系」。
2. 选择**源角色**与**目标角色**。
3. 填写**关系称谓**，按需要添加**关系备注**。
4. 点击「保存关系」。

也可以从画布上的连接点拖出连线，再在弹出的表单中补充关系。

关系带有方向。保存前按“源角色 → 目标角色”的方向核对称谓；不要把一条连线理解为两个角色文件都写入了对称关系。

## 查看和整理画布

角色节点可以拖动，画布支持缩放、筛选与定位角色。拖动只调整位置，不会改变角色关系。

节点位置和视口保存在**本机的画布布局**中。角色与关系内容来自作品文件；把作品复制到另一台设备时，不应依赖原设备的画布排布一并迁移。

筛选角色时，视图也会保留与命中角色直接关联的人物，便于查看周围关系。归档角色可通过「包含归档」显示。

## 修改或移除关系

点击关系连线或对应关系条目，打开编辑窗口。可以修改目标、称谓和备注；移除时选择「移除关系…」，再确认。

关系编辑会更新源角色文件中的关系字段。移除一条关系不会删除角色文件。

## 关系缺失或无法保存

| 现象                       | 处理方式                                           |
| -------------------------- | -------------------------------------------------- |
| 正文写了关系，图上没有连线 | 在关系表单中建立结构化关系                         |
| 目标角色无法解析           | 检查目标是否存在、是否为角色资产，以及引用是否明确 |
| 角色被隐藏                 | 清除筛选，检查归档状态                             |
| 文件有未保存编辑或外部变化 | 先处理文件状态，再重新打开关系表单                 |
| 布局保存失败               | 角色文件不受该布局错误影响；先确认文件内容已保存   |

需要建立角色资料或修复引用，见[资料库与资产](/guide/library)。
