# 搜索与定位

当前章节内的查找使用 `Ctrl+F`。寻找散落在不同章节和资料中的内容时，使用左侧「搜索」或 `Ctrl+Shift+F`。

## 搜索整部作品

1. 打开作品搜索，输入要查找的文字。
2. 选择搜索范围。需要时开启「区分大小写」。
3. 查看按文件分组的结果，每项显示命中文字、相对路径和行号。
4. 单击结果，在编辑器中打开文件并定位到相应段落。

| 搜索范围   | 用途                                   |
| ---------- | -------------------------------------- |
| 作品文件   | 在作品文件中进行一般查找               |
| 正文       | 检查人名、台词或情节在章节中的出现位置 |
| 创作资产   | 查找角色、设定、场景卡等资料           |
| 观察与摘要 | 回看 AI 协作产生的观察和摘要           |

例如，检查“林晚”是否在后续章节中改过称呼，可以先搜索正文，再切到创作资产核对姓名与别名。

## 结果为空或不完整

- **没有匹配文本**：缩短关键词，检查大小写及搜索范围。
- **达到本次搜索上限**：补全关键词或缩小范围，避免把当前列表当作全部结果。
- **存在未搜索文件**：展开「未搜索的文件与诊断」，查看具体文件及原因。

搜索不会代替保存。刚修改的段落没有搜到时，先保存文档再重新搜索。

## 结果能打开，但无法定位

如果出现“文件已变化或有未保存内容，请保存后重新搜索”，说明搜索时的文件版本与当前内容不一致。

先保存或处理[外部修改冲突](/guide/editor#external-conflicts)，再运行搜索。这样可以避免按旧位置跳到错误段落。

## 其他定位入口

资料库按标题、类型和状态组织资产，适合找“某个人物的资料”；全文搜索适合找“某句话出现在哪里”。审查结果还带有原文定位，见[独立审查](/ai/reviews)。
