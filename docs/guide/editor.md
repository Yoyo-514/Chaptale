# 编辑章节

正文和故事资料都可以在 Markdown 编辑器中打开。编辑器提供多标签、语法高亮、撤销重做、查找替换与字数显示。

## 创建和打开文档

从「文件 → 新建章节…」创建章节，或在文件树中打开已有 `.md` 文件。需要角色、设定等结构化资料时，使用[从模板新建](/guide/templates)。

Markdown 用少量符号表示结构，例如：

```md
# 第一章 雾港

船靠岸时，码头上只剩一盏灯。

## 未寄出的信

“你来晚了。”守夜人说。
```

章节和资料可以同时打开在不同标签中。关闭当前标签使用 `Ctrl+W`。

## 保存与恢复未保存内容

| 操作                | 入口                        |
| ------------------- | --------------------------- |
| 保存当前文档        | `Ctrl+S`，或「文件 → 保存」 |
| 保存全部文档        | `Ctrl+Shift+S`              |
| 切换自动保存        | 「文件 → 自动保存」         |
| 撤销 / 重做当前编辑 | `Ctrl+Z` / `Ctrl+Y`         |

保存后检查未保存标记是否消失。关闭标签或切换作品时，应用会提示处理未保存内容。

如果重新进入应用后出现草稿恢复提示，先核对草稿与磁盘版本。恢复的未保存内容仍需保存到文件中；它和[文档版本快照](/data/versions)用途不同。

## 查找和替换

`Ctrl+F` 查找当前文档，`Ctrl+H` 打开替换。需要跨章节查找名字、地点或一句台词时，用 `Ctrl+Shift+F` 打开[作品搜索](/guide/search)。

快捷键作用于当前焦点。焦点在 Agent 会话时，查找入口可能用于搜索会话内容。

## 引用资料与编辑文件头

可以用作品内双链引用其他文档，例如：

```md
[[角色/林晚.md]]
```

资产文件头里的字段描述类型、标题、关联角色等信息。界面提供对应的表单与源码入口；表单保存后更新同一份 Markdown 文件。

正文写作不必先掌握文件头语法。需要手动修改时，先了解[资料库中的文件结构](/guide/library#asset-files)。

## 处理“磁盘版本冲突” {#external-conflicts}

当其他编辑器或同步软件修改了同一文件，Chaptale 会检测变化。编辑器没有未保存修改时可以重读磁盘；两边都有变化时，需要处理冲突。

冲突窗口会并排显示**磁盘版本**和**本地未保存版本**：

| 选项     | 如何选择                                       |
| -------- | ---------------------------------------------- |
| 接受外部 | 使用磁盘中已有的内容，放弃当前未保存编辑       |
| 保留我的 | 确认以当前编辑器内容处理这次冲突               |
| 另存副本 | 为未保存内容指定另一个相对路径，先留住两份稿件 |

拿不准两份内容哪份完整时，先另存副本，再逐段核对。处理完成后，重新检查文件状态；生成候选、审查等操作也需要干净且已保存的正文。

## 长时间写作

「视图」菜单提供专注模式、主题和缩放。需要回看某次定稿或接受候选前的内容，打开[文档版本](/data/versions)；需要恢复整部作品，使用[作品备份](/data/backup)。
