# 开始使用

完成本页后，你会有一部保存在本机的作品，并写下、保存第一章。这个过程不需要配置模型或登录云盘。

## 下载与安装

在 [GitHub Releases](https://github.com/Yoyo-514/Chaptale/releases) 选择版本，再下载对应系统与处理器架构的安装包。

| 系统 | 文件格式 | 选择时注意 |
| --- | --- | --- |
| Windows x64 | `.exe` | 下载 Windows x64 安装包 |
| macOS | `.dmg`、`.zip` | Apple Silicon 选 arm64，Intel 选 x64 |
| Linux x64 | `.deb`、`.AppImage` | 按发行版及安装习惯选择 |

发布页提供 `SHA256SUMS.txt`，用于核对下载文件。当前没有应用内自动更新，后续版本仍从 Releases 获取。

## 创建第一部作品

首次启动会打开「新建作品」。如果已经关闭，可从「文件 → 新建作品…」重新进入。

1. 填写**作品名称**，例如“雾港来信”。
2. 选择**作品类型**：小说或剧本。
3. 填写**目录名**，选择**存放位置**。应用会在该位置下建立作品目录。
4. 保留「创建第一章」。按需要勾选角色、大纲等目录，也可以先使用默认选择。
5. 点击「创建并打开」。

成功后，左侧会出现作品目录，中央打开第一章；若不创建第一章，则打开创作守则。新建选项的用途见[创建和管理作品](/guide/workspace)。

## 写下并保存第一章

1. 在左侧打开 `正文/0001-第一章.md`。
2. 在标题下写一段正文。
3. 按 `Ctrl+S`，或选择「文件 → 保存」。
4. 确认保存完成、未保存标记消失。

也可以在「文件」菜单开启自动保存。想直接在磁盘中查看文件，到「设置 → 作品」确认当前作品路径。

::: tip 已有稿件
可以先创建作品，再将已有 Markdown 稿件复制到正文目录。Word、PDF 等格式需要先在其他工具中转换；此流程不包含格式转换。有关文件夹与资料识别，见[管理作品](/guide/workspace)。
:::

## 加入一份角色资料

打开左侧「资料库」，通过「从模板新建」选择角色模板，填写姓名等字段并创建。角色资料保存为作品内的文件，之后可以通过表单或编辑器继续补充。

模板除了角色，还包括地点、物品、伏笔、大纲和场景卡。见[资料库与资产](/guide/library)。

## 接下来做什么

- 想熟悉各区域和菜单：阅读[认识工作台](/guide/interface)。
- 想集中写作：阅读[编辑章节](/guide/editor)，了解专注模式、保存和冲突处理。
- 想接入 AI：先看[协作流程](/ai/workflow)，再[配置模型](/ai/models)。
- 要开始长期写作：了解[备份与恢复](/data/backup)，为作品保留独立副本。

::: info 保存到哪里
保存会写入本机作品目录。云端备份需要另外配置；即使目录位于 OneDrive 下，也要通过 OneDrive 客户端确认上传状态。
:::
