# 故事时间线

故事时间线将事件按你设定的故事顺序排列。它适合核对“哪件事先发生”“两条故事线如何交错”，也能从事件跳回角色、地点与章节。

从「资料库」打开「故事时间线」。

![故事时间线：顺序、时间描述、故事线及关联资料](/screenshots/timeline.png)

## 新建事件

1. 点击「新建事件」。
2. 填写事件名称、故事顺序和故事时间。
3. 按需要填写故事线、事件摘要、相关角色、关联章节和地点。
4. 确认保存目录与文件名，创建文件。

新建时，顺序默认接在现有事件之后；如果已经按故事线筛选，也会带入当前故事线。

## 顺序与时间分别控制什么

| 字段     | 作用                               | 示例                               |
| -------- | ---------------------------------- | ---------------------------------- |
| 故事顺序 | 决定事件在时间线中的排列，使用数字 | `1`、`2`、`2.5`                    |
| 故事时间 | 向读者显示发生时间，允许自定义历法 | 清河历八年冬，子夜之后             |
| 故事线   | 对事件分组和筛选                   | 归途、港口调查                     |
| 关联章节 | 指向叙述此事件的章节               | 第一章                             |
| 状态     | 标记计划、确认或归档               | `planned`、`confirmed`、`archived` |

**故事时间不会自动换算为排序。** 例如“昨日”和“次日”都是描述文字，要靠故事顺序确定前后。尚未填写顺序的事件会集中在「未排序事件」中。

## 查看与编辑

- 输入关键词，筛选事件标题、路径或摘要等信息。
- 选择故事线，只看相关事件。
- 勾选「包含归档」，找回被默认隐藏的归档事件。
- 点击事件标题，打开 Markdown 源文件。
- 点击「编辑事件」，修改结构化字段。
- 点击关联角色、章节或地点，查看对应资料。

要在两个事件之间插入新事件，可以给它一个中间的顺序值，例如 `2.5`，无需立刻重排整条时间线。

## 为什么事件没显示

先检查是否被关键词或故事线筛选隐藏，再确认资产类型是故事事件、状态是否归档。普通章节中的一段叙述不会自行变成时间线事件。

[章节结算](/ai/settlement)也能提出时间线事件；提议需要被接受并写入资料后，才成为正式可用的事件记录。
