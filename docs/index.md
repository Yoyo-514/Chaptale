# Chaptale 使用手册

手册正在随新版界面重写，目前只有下面这一节。

## 让助手按意思查找作品内容

助手查找作品内容有两种方式：按关键词，和按意思。按关键词不需要任何设置；按意思要先接上一个 embedding 服务，并为作品建立索引。

### 1. 填写检索服务

打开“设置 → 检索”，填写：

- **服务地址**：OpenAI 兼容接口的地址，例如 `https://api.siliconflow.cn/v1`。应用会把请求发到这个地址下的 `/embeddings`。
- **API 密钥**：服务不需要密钥时留空。保存后不再显示，留空表示沿用已保存的。
- **模型名**：例如 `Qwen/Qwen3-Embedding-8B`。
- **向量维度**：留空时用模型的默认值，只有模型支持调整维度时才需要填。

点“测试连接”，成功后会显示服务返回的向量维度。确认无误再点“保存”。

### 2. 为作品建立索引

打开一部作品，点助手输入框下方左侧的数据库图标，再点“建立索引”。应用会先告诉你要发送多少段、多少字、发往哪个服务，确认后开始。

- 建立在后台进行，可以关掉弹层继续写作。
- 点“停止”可以随时中断，已经算好的段落会保留，之后点“继续建立”接着算。
- 建立失败时会收到通知，弹层里保留失败原因。

在线服务会收到作品的文字，并可能按用量计费。在你点“建立索引”之前，应用不会把这部作品的文字发给检索服务。

### 3. 之后会发生什么

- 你改过或新写的段落不需要手动更新：助手按意思查找时会先为这些段落补算，再查找。
- 换了模型或向量维度后，旧索引不能再用，需要在弹层里点“重建索引”。只改服务地址或密钥不需要重建。
- 检索服务没有设置、索引还没建，或服务出错时，助手只按关键词查找，并在这一步的详情里写明原因。
- 索引只保存在这台设备上，不随作品包导出。作品到了新设备需要重新建立。

### 在对话里看检索结果

展开对话里的“检索”步骤，可以看到每条结果来自“关键词”“语义”还是“两者”，语义结果附相似度。相似度只表示与问题的接近程度，最接近的 20 段总会返回，是否真的相关以原文为准。
