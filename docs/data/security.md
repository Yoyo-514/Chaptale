# 文件、权限与隐私

作品保存在本机；模型调用、联网工具和云端备份会按各自配置访问外部服务。是否发送数据，取决于你使用的功能和授权。

## 数据分别放在哪里

| 数据                   | 位置与查看入口                                       |
| ---------------------- | ---------------------------------------------------- |
| 正文、角色、设定、事件 | 选定的作品目录；「设置 → 作品」显示根路径            |
| 作品内部记录           | 作品中的 `.chaptale/` 等目录；作品设置可显示内部文件 |
| 会话记录               | 按作品保存；作品设置显示当前会话目录                 |
| 模型与其他本机配置     | 「设置 → 配置文件」显示实际路径                      |
| 画布布局等界面状态     | 本机应用存储，不应假定随作品目录迁移                 |

复制作品时应包含隐藏目录；只复制正文会遗漏资料与部分协作记录。模型凭据和用户级设置需在新设备单独核对。

## 使用 AI 时会发送什么

| 功能             | 可能发送的数据                             | 接收方                 |
| ---------------- | ------------------------------------------ | ---------------------- |
| Agent 对话       | 对话上下文、附加文件、工具读取并带入的资料 | 配置的模型服务         |
| 候选、审查、结算 | 相应目标内容、参考和任务提示               | 本次所选模型服务       |
| 联网搜索         | 搜索词与服务所需请求信息                   | 配置的搜索服务         |
| 网页抓取         | 对目标网页的请求                           | 目标站点及相关提取流程 |
| 云端备份         | 作品归档                                   | 已登录并绑定的云盘服务 |

`SYSTEM.md` 和 `APPEND_SYSTEM.md` 中的提示词也会随模型请求发送。不要把密钥放入提示词、作品正文或待分享的专员说明。

本地优先描述的是文件保存方式，不是“所有功能均不联网”。模型服务如何保留请求数据，需要查阅你所用服务的说明。

## 授权工具操作

Agent 请求需要授权的操作时，界面会显示具体请求。先检查工具、目标路径及操作范围，再选择允许或拒绝。

| 授权范围       | 影响                           |
| -------------- | ------------------------------ |
| 单次或会话规则 | 临时影响当前请求或会话         |
| 本作品持久规则 | 对当前作品生效，随作品文件保存 |
| 全局持久规则   | 影响本机所有作品               |

在「设置 → 权限」中可以查看允许、拒绝或每次询问的持久规则，并删除不再需要的规则。单次与会话规则不显示在该列表中。

删除一条规则表示后续操作不再从**这条规则**获得权限，不代表其他规则也被一并清除。导入或接手作品后，也应查看它携带的作品级规则。

## 联网开关的范围

关闭联网搜索会让 `web_search` 提示离线；网页抓取、缓存检索和模型请求不受这个开关统一控制。

网页抓取的超时、大小上限和内网放行规则在「设置 → 联网」中单独配置。没有访问内网资源的实际需要时，保留默认放行范围。

## 分享资料或提交问题

- 截图前检查是否显示正文、路径中的个人信息或密钥。
- 不要直接上传包含凭据的 `models.json` 或联网配置文件。
- 运行输出可能包含作品原文，先脱敏再作为故障附件。
- 导出专员与技能时，检查正文说明中是否夹带个人资料。

设置路径与诊断入口见[设置速查](/reference/settings)；完整作品副本的处理见[备份与恢复](/data/backup)。
