# 文档版本与定稿

文档版本保存关键操作时的文件快照，用于比较旧稿和恢复某个章节。它与编辑器撤销、自动保存、整部作品备份各有用途。

## 保存、版本与备份的区别 {#save-version-backup}

| 机制            | 保存什么               | 适合解决什么问题                   |
| --------------- | ---------------------- | ---------------------------------- |
| 手动 / 自动保存 | 当前文件内容           | 把编辑器中的稿件写到磁盘           |
| 撤销 / 重做     | 编辑过程中的操作       | 改回刚刚输入或删除的内容           |
| 文档版本        | 特定操作节点的文件快照 | 回看接受候选、结算或定稿前后的稿件 |
| 作品备份        | 整部作品归档           | 迁移、另存完整副本或恢复多份文件   |

文档版本不会为每次按键或每次自动保存创建快照。刚开始纯手动写作时，版本列表为空可能是正常情况。

## 查看历史快照

1. 打开目标文件，保存并处理外部变化。
2. 选择「写作 → 查看文档版本」。
3. 在历史版本列表中按时间和原因选择一条记录。
4. 比较左侧“历史快照”和右侧“当前版本”。

记录原因包括接受前、结算前、定稿前、定稿、回滚前和回滚。文件与快照一致时，界面会直接提示，回滚按钮不可用。

## 回滚当前文件

读完差异后，点击「回滚到该版本」。回滚前会保留当前内容的快照，便于之后核对或恢复。

回滚只处理目标文档，不会同时还原角色资料、会话、候选记录或整部作品。例如，回滚正文后，之前接受的角色状态提议仍需单独检查。

如果目的是恢复多个文件在同一时期的内容，应查看[作品备份](/data/backup)。

## 定稿当前章节

1. 保存当前章节。
2. 选择「写作 → 定稿当前章节」。
3. 核对目标文件，点击「确认定稿」。

定稿会保存正文快照，并将章节标记为已定稿。它用于确认一个写作节点，不是只读锁，也不会自动生成云端备份。

[章节结算](/ai/settlement)负责整理摘要和事实；是否结算、何时定稿，应按你的写作进度分别决定。
