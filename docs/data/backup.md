# 云端备份与恢复

「设置 → 云端备份」通过 Dropbox 或 OneDrive 保存作品归档。备份需要可用的云服务、已登录账户，以及当前作品的备份位置绑定。

本机文件保存、云盘客户端同步与 Chaptale 归档是不同的操作。云端备份不会把作品目录变成实时双向同步盘。

## 开始前检查

| 检查项         | 在哪里确认                                                 |
| -------------- | ---------------------------------------------------------- |
| 当前作品已打开 | 「设置 → 作品」                                            |
| 作品身份有效   | 作品根目录中的 `chaptale.json`；缺失或无效时按页面提示处理 |
| 服务已配置     | 云端备份页的账户状态                                       |
| 账户已登录     | 对应服务显示登录后的账户信息                               |
| 文档已保存     | 使用「文件 → 全部保存」                                    |

服务是否可用取决于应用构建时的配置。显示「未配置」时，只填写个人账号无法启用该服务；仍可通过复制完整作品目录保留本机备份。

## 完成首次备份

1. 在「账户」区域，对可用服务点击「登录」，完成授权。
2. 打开该服务的「云端目录」。
3. 进入存放归档的目录，选择「用作备份位置」。
4. 回到「作品备份」，核对服务与绑定目录。
5. 点击「立即备份」，等待完成并检查归档列表。

云端目录浏览以服务授权给应用的范围为准，不能据此浏览账户内所有文件。绑定只保存在本机；解除绑定不会删除已经上传的归档。

## 自动备份

在作品备份区域开启「自动备份」并设置间隔。它只在应用运行、当前作品打开时执行；备份或恢复正在进行时会跳过。

离开应用后不应期待它继续在后台定时归档。出现失败提示后，先解决账户、网络或目录问题，再检查是否已经产生新的可用归档。

## 恢复归档

选择归档并点击「恢复…」。先检查恢复计划中的**新增、一致、冲突、本地独有**文件，再选择恢复方式。

| 方式 | 会发生什么                               | 适用情况                         |
| ---- | ---------------------------------------- | -------------------------------- |
| 新增 | 解包到作品旁的新目录，当前作品不变       | 先检查旧稿、迁移或不确定应选哪份 |
| 覆盖 | 先保留快照，再原地还原；本地独有文件保留 | 确认需要用归档恢复当前目录       |
| 合并 | 对差异文件逐项决定处理方式               | 本地与归档各有需要保留的内容     |

归档缺少作品身份信息，或身份与当前作品不符时，只能选择「新增」。

### 合并时处理冲突

点击「对比」查看文本差异，再为文件选择：

- **用归档**：采用归档内容。
- **用本地**：保留当前内容。
- **两个都留**：保留两份，之后自行整理。

尚未决定的冲突文件不会被写入，本地保持不动。`.chaptale/` 应用数据也可能存在冲突，要结合正文、历史和提议记录一起判断。非文本或过大的文件无法在应用内显示文本差异。

### 恢复后检查

查看恢复回执中的目标位置、写入数量、未写入项和还原前快照。使用「新增」恢复的目录尚未绑定云端位置，需要打开并重新检查配置。

恢复不会用磁盘内容覆盖编辑器里尚未保存的缓冲。因此恢复前应先保存或处理未保存文档，恢复后再确认编辑器与磁盘状态。

## 删除归档与解除绑定

解除绑定只取消本机作品与云端位置的关联。删除归档则会移除所选云端文件，确认后无法从该列表恢复；不要把两种操作混为一谈。

云端账户凭据经过系统安全存储机制处理并保存在本机。这不代表上传的作品归档自动获得应用层加密。

## 使用 OneDrive 本机目录

如果作品直接放在 OneDrive 同步目录，文件上传由 OneDrive 官方客户端负责。「文件 → 文件与同步…」可用于检查本机位置及相关状态。

无论哪种方式，确认备份成功应以实际归档或客户端上传状态为准，不能只看编辑器已保存。
