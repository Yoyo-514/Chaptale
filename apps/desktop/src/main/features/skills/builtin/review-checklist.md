# 审查清单

对给定正文做系统化检查。**只报告问题，不动手改**；每个问题给出位置、依据与最小修改建议。

## 执行顺序

按 **连贯性 → 人物 → 文风** 的顺序检查：连贯性问题是硬伤（读者会出戏、后文会塌），必须最先排查；文风问题是打磨项，放最后。报告同样按此排序——硬伤优先，同维度内按严重度排。

## 连贯性

- 时间线：事件顺序、间隔天数、人物年龄与季节是否自洽；
- 空间：人物位移是否可能（上一场在 A 城，本场突然在 B 城无过渡）；
- 道具状态：物品的获得/损坏/转手记录是否连续；
- 设定一致：能力规则、组织关系、称谓体系与既有设定是否冲突；
- 信息泄露：人物是否说出了他此刻不该知道的事；伏笔是否提前揭露。
- **典型误报**：叙述视角的有限知情不是信息泄露——视角人物对真相的错误猜测、旁白刻意隐瞒的信息，属于叙事手法，不报。

## 人物

- 行为动机：关键决定是否有铺垫，是否符合已建立的性格；
- 语言指纹：对白风格是否与人物身份/教育背景一致，不同人物是否可区分；
- 关系温度：亲疏变化是否有事件支撑，无端升温/降温即问题。
- **典型误报**：人物在极端情境下的失常言行不是性格崩坏——若文本已给出足够压力铺垫（至亲遇害后的暴怒），属于合理反应，不报。

## 文风

- 视角纪律：是否越出视角人物的感知范围（偷窥他人内心）；
- 重复：口头禅式的词语/句式高频重复；
- 节奏：连续多段同长句式，或高潮段落被冗余描写稀释。
- **典型误报**：人物标志性口癖的重复不是文风问题——作者有意为之的语言指纹（某人物每次开口都带"依我看"），是塑造手段，不报。

## 报告格式

每个问题一条，按严重度排序：

```
[高|中|低] <位置引述原文片段> — <问题描述> — 建议：<最小修改方案>
```

三行示例：

```
[高] "林晚摸出袖中账本"（第 4 章） — 账本已于第 3 章末被账房先生收回，此处凭空出现 — 建议：补一句她誊抄了缺页前后的条目，此处改为"摸出誊抄的纸页"
[中] "会长慈爱地笑了，心里盘算着下一步"（第 5 章） — 林晚视角越界，偷窥了会长内心 — 建议：删"心里盘算着下一步"，改为林晚可观察的外部细节
[低] "夜色如墨"（第 5 章，本章第 3 次） — 同一意象短距离重复 — 建议：后两处换用不同的夜景描写
```
