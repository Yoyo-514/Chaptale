# 最小改动改写法

改写的目标是**修复指定问题**，不是重写。作者的文风、句式习惯、叙事节奏是资产，不是待优化项。

## 最小改动判定标准

**能改一个词就不改一句，能改一句就不改一段。** 对每个问题，从最小粒度开始尝试：

1. 换/删/补一个词能修复 → 只动这个词；
2. 词级修不了，重写这一句 → 句内其余措辞尽量沿用原文；
3. 句级修不了（逻辑跨句），才动到段 → 段内无关句一字不动；
4. 段级也修不了的结构性矛盾 → 不改，标注"需作者决策"。

## 步骤

1. **确认问题清单**：来自审查结果或作者指示；无清单时先向作者要，不猜测；
2. **定位问题句**：找到每个问题对应的最小文本范围，按上述标准定粒度；
3. **列出必须保留的风格要素**：动笔前先列三类——人物口癖（"依我看"这类标志性用语）、句长节奏（原文爱用短句就不合并成长句）、意象系统（原文用"药香/秤杆"意象就不换成无关意象）；
4. **生成改稿**：逐处改写，其余原样保留，不擅自增删情节信息、不新增设定；
5. **自查 diff 范围**：逐句对照改前改后，确认每处改动都对应清单里的一个问题；出现无对应问题的改动，还原它。

## 改前/改后对照示例

问题：林晚此时尚未见过账本，原句却写她"认出"。

```
改前：林晚一眼认出那是师父的账本。
改后：林晚猜想那多半是师父的账本。
为什么这样改：只把"一眼认出"换成"猜想……多半是"，修复知情越界；句式、语序、其余用词全部保留。
```

## 输出格式

```markdown
## 改写稿

（全文，未改动部分原样保留）

## 改动清单

1. 「原文片段」→「改后片段」：修复 <问题>，理由 <一句话>
```

## 禁止

- **红线：不顺手修复未被指出的问题**——改写过程中发现清单外的新问题，写进"另议清单"报给作者，不动原文；
- 不改变视角、时态、人称；
- 对无法在最小改动内修复的问题（结构性矛盾），标注"需作者决策"而不是大改。
