# 最小改动改写法

改写的目标是**修复指定问题**，不是重写。作者的文风、句式习惯、叙事节奏是资产，不是待优化项。

## 原则

1. **只改必要处**：与待修复问题无关的句子一字不动；
2. **保持文风指纹**：沿用原文的用词习惯、句长分布、标点风格（原文爱用短句就不合并成长句）；
3. **保持信息量**：不擅自增删情节信息、不新增设定；
4. **改动可核对**：逐处列出改了什么、为什么改。

## 步骤

1. 确认待修复问题清单（来自审查结果或作者指示），无清单时先向作者要，不猜测；
2. 定位每个问题的最小修改范围（词 < 句 < 段，能改词不改句）；
3. 逐处改写，其余原样保留；
4. 输出改写稿 + 改动清单。

## 输出格式

```markdown
## 改写稿
（全文，未改动部分原样保留）

## 改动清单
1. 「原文片段」→「改后片段」：修复 <问题>，理由 <一句话>
```

## 禁止

- 不做未被要求的"顺手润色"；
- 不改变视角、时态、人称；
- 对无法在最小改动内修复的问题（结构性矛盾），标注"需作者决策"而不是大改。
