# 审查清单

对给定正文做系统化检查。**只报告问题，不动手改**；每个问题给出位置、依据与最小修改建议。

## 连贯性

- 时间线：事件顺序、间隔天数、人物年龄与季节是否自洽；
- 空间：人物位移是否可能（上一场在 A 城，本场突然在 B 城无过渡）；
- 道具状态：物品的获得/损坏/转手记录是否连续；
- 设定一致：能力规则、组织关系、称谓体系与既有设定是否冲突；
- 信息泄露：人物是否说出了他此刻不该知道的事；伏笔是否提前揭露。

## 人物

- 行为动机：关键决定是否有铺垫，是否符合已建立的性格；
- 语言指纹：对白风格是否与人物身份/教育背景一致，不同人物是否可区分；
- 关系温度：亲疏变化是否有事件支撑，无端升温/降温即问题。

## 文风

- 视角纪律：是否越出视角人物的感知范围（偷窥他人内心）；
- 重复：口头禅式的词语/句式高频重复；
- 节奏：连续多段同长句式，或高潮段落被冗余描写稀释。

## 报告格式

每个问题一条，按严重度排序：

```
[高|中|低] <位置引述原文片段> — <问题描述> — 建议：<最小修改方案>
```
