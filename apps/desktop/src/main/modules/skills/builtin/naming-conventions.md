# 命名与译名一致性

命名混乱是长篇最常见的硬伤：同一人物前后异名、译名中英混用、功法称谓漂移。本技能约定命名的建立与核对方法。

适用时机：新命名诞生时执行「建立」部分；审查或交稿前执行「检查」部分。

## 检查范围

一致性检查覆盖五类专有名词：

- **人名**：本名、昵称、外号、蔑称及其写法变体；
- **地名**：城池、街巷、山川、店铺（"回春堂/回春药铺"算漂移）；
- **组织**：门派、商会、官署及其简称（"漕运商会/商会"需确认指同一家）；
- **功法或术语**：功法、招式、职阶、世界观专有概念的固定写法；
- **译名**：外文名的唯一中文写法（"Kael=凯尔"），全文不混用原文与译名。

## 建立名词对照表

- **首次出现即登记**：任何专有名词第一次在正文出现，立即登记一行——名称、类别、别称/变体、首次出现位置；
- 登记时确认与既有条目不冲突：同音、近形、缩写撞车；主要人物之间避免声母韵母高度相似（"林霜/凌双"）；
- 术语在人物口语中的惯用简称一并登记为别称（"九转还魂丹/还魂丹"），叙述用全称、对白可用简称；
- **称谓随关系变化的规则也要登记**：谁在什么关系阶段用哪个称谓（侍女青儿：决裂前称林晚"小姐"，决裂后直呼其名），关系转折发生时更新规则。

## 检查步骤

1. **grep 全部变体**：对表中每个名词，搜索其本名、别称、易错写法（同音/近形字替换后的写法），统计各变体出现的章节与次数；搜不到任何变体的条目标记为「未使用」，供作者决定是否从表中移除；
2. **对照表核对**：逐个确认写法与对照表一致、称谓使用符合当时的关系阶段；发现表中没有的新名词，先补登记再核对；近形/同音名互查一遍，确认不存在读者易混的对；
3. **报告不一致处及首次出现位置**：每处不一致给出各变体的分布与首次出现位置，便于判断哪个写法是正宗；只报告，不直接改文。

## 示例对照表

| 名称 | 类别 | 别称/变体 | 称谓规则 | 首次出现 |
| ---- | ---- | -------- | -------- | -------- |
| 林晚 | 人名 | 晚丫头（师父）、林姑娘（外人） | 青儿：决裂前"小姐"，决裂后直呼其名 | 第 1 章 |
| 回春堂 | 地名 | 无（禁用"回春药铺"） | — | 第 1 章 |
| Kael | 译名 | 凯尔（唯一写法，正文不用原文） | — | 第 2 章 |

## 报告格式

每条带类别标签，给出证据分布与建议，按影响面排序：

```
[不一致] "萧炎" / "萧焱" 混用：第 3 章用前者 12 次，第 5 章用后者 2 次；首见第 1 章作"萧炎" — 建议统一为「萧炎」
[易混]   "林霜"(主角盟友) 与 "凌双"(反派) 读音接近 — 建议改名其一
[称谓]   侍女青儿在决裂章节后仍称"小姐"（第 7 章 2 处） — 确认是否有意保留
```
