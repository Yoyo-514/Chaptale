# 命名与译名一致性

命名混乱是长篇最常见的硬伤：同一人物前后异名、译名中英混用、功法称谓漂移。本技能约定命名的建立与核对方法。

## 建立命名时

- 新命名一旦在正文使用，立即确认它与既有名录不冲突（同音、近形、缩写撞车）；
- 人名注意读音区分度：主要人物之间避免声母韵母高度相似（"林霜/凌双"）；
- 外文名/译名定一个唯一写法（"Kael=凯尔"），全文不混用原文与译名；
- 称谓体系分层：正式名、昵称、外号、敌对方蔑称——每个人物的称谓集合要有记录，谁在什么关系下用哪个称谓。

## 核对方法

1. 从文本中提取所有专有名词（人/地/物/组织/功法）；
2. 对照既有名录（设定文件、前文），逐个确认写法一致；
3. 近形/同音名互查：是否存在读者易混的对；
4. 称谓使用核查：人物 A 对人物 B 的称谓是否符合两人当前关系阶段。

## 报告格式

```
[不一致] "萧炎" / "萧焱" 混用：第 3 章用前者 12 次，第 5 章用后者 2 次 — 建议统一为「萧炎」
[易混]   "林霜"(主角盟友) 与 "凌双"(反派) 读音接近 — 建议改名其一
[称谓]   侍女青儿在决裂章节后仍称"少爷" — 确认是否有意保留
```
