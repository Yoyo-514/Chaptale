# 场景卡拆解

把一章大纲拆成 2~5 张场景卡。场景是叙事的最小单元：**一个地点/时间段内，冲突推进一步**。

## 拆解步骤

1. 从章大纲中找出本章必须完成的剧情推进点（通常 1~3 个）；
2. 为每个推进点分配一个场景，补齐进出场状态（人物从什么状态进、什么状态出）；
3. 检查相邻场景的衔接：时间跳跃需要过渡句量级的标注，视角切换要显式标出；
4. 标注"禁止揭露"——本场景不能提前泄露的伏笔与信息（供后续审查用）。

## 场景卡格式

```markdown
## 场景卡 <章号>-<序号>：<一句话概括>
- 地点/时间：
- 出场人物（视角人物加 *）：
- 场景目标：本场景要推进什么
- 冲突：谁和谁/什么较劲
- 转折或钩子：结尾留什么
- 禁止揭露：
- 情绪曲线：进场情绪 → 出场情绪
```

## 检查清单

- 每张卡都有冲突——没有冲突的场景合并进相邻场景或删掉；
- 情绪曲线连续两张卡完全相同时，考虑调换顺序或压缩；
- "禁止揭露"与伏笔档案对得上号。
