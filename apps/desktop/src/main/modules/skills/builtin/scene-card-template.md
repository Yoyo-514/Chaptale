# 场景卡拆解

把一章大纲拆成 2~5 张场景卡。场景是叙事的最小单元：**一个地点/时间段内，冲突推进一步**。

## 字段定义

每字段一句话解释，附示例值：

- **地点/时间**：卡头行，交代场景发生在哪、何时。示例：商会账房 / 当夜。
- **出场人物**：卡头行，本场景登场的人物，视角人物加 *。示例：林晚*、账房先生。
- **场景目标**：本场景必须完成的剧情推进，一场只推进一件事。示例：让林晚拿到师父的账本。
- **入场状态**：视角人物进场时的处境与情绪。示例：林晚深信会长是恩人，只想借账本核对药材。
- **冲突与阻力**：谁/什么在阻止场景目标达成。示例：账房先生借口盘点拒绝交出账本。
- **转折点**：场景内改变局面或认知的那一刻，同时考虑场景结尾留下什么钩子牵住下一场。示例：账本缺了师父出事当月的那一页。
- **出场状态**：人物离场时的处境与情绪，须与入场状态有差。示例：林晚起疑，但仍不愿相信与会长有关。
- **禁止揭露**：本场景不能提前泄露的伏笔与信息。示例：撕页的人是会长本人。
- **情绪曲线**：入场情绪 → 出场情绪的一条线。示例：安心 → 不安。

## 拆解步骤

1. **找状态变化点**：通读章大纲，标出人物处境或认知发生变化的每一处（获得信息、关系转变、局面逆转）；
2. **每个变化点一张卡**：变化点即场景的转折点，围绕它补齐其余字段；没有变化点的内容并入相邻卡或删掉；
3. **检查衔接**：逐对核对相邻卡——前一张的出场状态应能自然导出后一张的入场状态；时间跳跃标注过渡量级，视角切换显式标出。

## 完整示例卡

```markdown
## 场景卡 3-2：账本缺页

- 地点/时间：商会账房 / 当夜
- 出场人物（视角人物加 *）：林晚*、账房先生
- 场景目标：让林晚拿到师父的账本
- 入场状态：林晚深信会长是恩人，只想借账本核对药材
- 冲突与阻力：账房先生借口盘点拒绝交出账本
- 转折点：账本缺了师父出事当月的那一页；缺页去向留作下一场钩子
- 出场状态：林晚起疑，但仍不愿相信与会长有关
- 禁止揭露：撕页的人是会长本人
- 情绪曲线：安心 → 不安
```

衔接示例：卡 3-2 出场状态「起疑，但仍不愿相信」→ 卡 3-3 入场状态应从「起疑但压抑」起步，不能直接跳到「决意报复」。

## 检查清单

- 每张卡都有冲突——没有冲突的场景合并进相邻场景或删掉；
- 一章超过 5 张卡说明章大纲过载，先建议拆章再拆卡；
- 情绪曲线连续两张卡完全相同时，考虑调换顺序或压缩；
- 每张卡的转折点是否给场景结尾留了牵住下一场的钩子；
- **红线：禁止揭露字段必须与伏笔清单逐条对照**——伏笔清单里尚未到揭露章节的项，出现在本场景相关人物/道具上时，必须写进禁止揭露。
