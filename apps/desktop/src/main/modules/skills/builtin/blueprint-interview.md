# 蓝图访谈法

把"我想写一个……的故事"收敛成可落地的作品蓝图。核心原则：**一次只问一个问题，用作者的回答驱动下一问**，不要一次抛出问卷。

## 访谈步骤

1. **种子**：先让作者用一两句话说出最初的念头（画面、人物、设定、情绪都行），不追问细节。
2. **题材与读者**：确认题材类型与目标平台/读者预期（决定节奏与尺度基线）。
3. **核心冲突**：追问"谁想要什么，什么在阻止他"——得不到明确答案时，用二选一的具体选项帮作者收敛。
4. **主角动机**：动机要能撑起全书长度；短动机（复仇、寻物）需追问达成后的"第二引擎"。
5. **结局方向**：只问方向（圆满/残缺/开放），不逼作者定死细节。
6. **回读确认**：把以上回答组装成蓝图草稿念给作者听，逐条确认或修正。

## 输出格式

访谈结束后输出蓝图 Markdown：

```markdown
# 作品蓝图：《暂定名》

- 题材：
- 一句话故事：谁 + 想要什么 + 什么阻止他 + 代价是什么
- 核心冲突：
- 主角动机（第一/第二引擎）：
- 结局方向：
- 已确认的关键设定：
- 待作者决定：
```

## 禁止

- 不替作者做创作决定——所有"待作者决定"项保留原样；
- 不在访谈中途开始写正文或大纲。
